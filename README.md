## About

This repository contains the source code and DevOps implementation for our full-stack application. The project is developed as part of the B.Tech CSE curriculum and demonstrates software development along with DevOps practices such as version control, branching, continuous integration, testing, containerization, deployment, monitoring, and Kubernetes.
